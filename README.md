# Deck: Twelve Labours
> 헤라클레스의 12과업에서 영감을 받은, 필드 탐험과 턴 기반 카드 전투를 결합한 2D 게임.

[게임 다운로드 · itch.io](https://hong0723.itch.io/deck-twelve-labours) · [게임 소스 · develop](https://github.com/Hong0723/Deck-Twelve-Labours/tree/develop)

## 플레이 영상 · 스크린샷
추후 추가 예정입니다.

## 게임 소개
필드를 탐험하며 적과 만나 카드 전투를 진행하고, 획득한 아이템과 보상으로 다음 전투를 준비합니다. 탐험 중의 대화·퀘스트와 손패·마나를 활용하는 전투를 연결한 게임입니다.

## 주요 특징
- 2D 필드 탐험과 대화·퀘스트
- 손패와 마나를 활용하는 턴 기반 카드 전투
- 드로우·카드 사용·버리기로 이어지는 카드 순환
- 전투 보상 선택 및 인벤토리 관리
- 포털을 통한 구역 이동과 탐험·전투 전환

## 실행 방법
**배포 버전:** 위 itch.io 링크에서 배포 파일을 내려받아 실행합니다.

**Unity 프로젝트:** 실제 게임 소스는 **`develop` 브랜치**에 있습니다.

```bash
git clone --branch develop https://github.com/Hong0723/Deck-Twelve-Labours.git
```

Unity Hub에서 저장소 루트를 추가하고 **Unity 6000.2.6f2**로 엽니다. 패키지 복원 후 시작 씬을 실행합니다.

외부 에셋 및 라이브러리의 권리는 각 제작자에게 있습니다.
